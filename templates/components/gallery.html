{# Inline gallery embedded in article prose. Declare the galleries in the page's front matter as a list, giving each one a unique `name` and its own `images`, then invoke the component where you want a gallery to appear, passing the whole list, the name to render and the colocated base path: [[extra.galleries]] name = "harbor" images = [ { src = "harbor-1.svg", alt = "Boats at dusk", caption = "Golden hour." }, { src = "harbor-2.svg", alt = "Empty pier" }, ] {{ }} Multiple galleries per article are supported: give each one its own `name` and a matching component call. The `name` also scopes the anchor IDs so galleries navigate independently. The preview shows the first `preview` thumbnails (default 3) with a "+N" overlay when there are more; the lightbox always lets you page through every image, scoped to just this gallery's entries. #} {%- component gallery(galleries, name, base_path="", preview=3) -%} {%- set_global images = [] -%} {%- for g in galleries -%}{%- if g.name == name -%}{%- set_global images = g.images -%}{%- endif -%}{%- endfor -%} {%- set total = images | length -%}
{%- for img in images %} {%- if loop.index > preview %}{% break %}{% endif %} {%- endfor %} {%- if total > preview %}+{{ total - preview }}{% endif %}
{{ }} {%- endcomponent gallery %}
