{# Inline gallery embedded in article prose. Declare the images in the page's front matter under a named key, then invoke the component where you want the gallery to appear, passing the image list, the colocated base path and a unique id prefix: [extra.galleries.harbor] images = [ { src = "harbor-1.svg", alt = "Boats at dusk", caption = "Golden hour." }, { src = "harbor-2.svg", alt = "Empty pier" }, ] {{ }} Multiple galleries per article are supported: give each one its own key and its own component call with a distinct `id_prefix`. The preview shows the first `preview` thumbnails (default 3) with a "+N" overlay when there are more; the lightbox always lets you page through every image, scoped to just this gallery's entries. #} {%- component gallery(images, id_prefix, base_path="", preview=3) -%} {%- set total = images | length -%}
